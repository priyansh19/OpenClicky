faq

questions, answered

what is openclicky?

a small companion for your desktop. hold right ctrl, ask about whatever is on your screen, and it answers out loud while a blue triangle points at the right spot. it's an open-source take on the clicky idea, built windows first.

is it really free?

yes. it's MIT licensed, and the windows installer includes a local model and voices, so it works without an account or an api key. the mac and linux builds start you on a cloud model with your own key for now. if you use a cloud key, you pay that provider directly.

does it watch my screen all the time?

no. it only captures while you're holding the key, shows that it's looking, and throws the screenshot away when the answer is done.

where do my screenshots and voice go?

with the built-in model, nowhere: everything runs on your computer. with a cloud model, the screenshot and your question go to the provider you picked. the privacy doc in the repo lists exactly what each provider receives.

which apps does it work with?

anything you can see. it reads the screen like you do, so it works with office apps, browsers, editors, games and settings pages alike.

does it run on mac or linux?

windows is the main target and the best tested. mac and linux (x11) builds come from the same code and are published with each release as early builds.

windows says the app is unrecognised. is that ok?

the builds aren't code-signed yet, so smartscreen warns on first launch. choose “more info”, then “run anyway”. you can also build it yourself from source.

is this the official clicky?

no. openclicky is an independent open-source project inspired by farzaa/clicky. it isn't affiliated with heyclicky.

how can i help?

try it, file issues, or send a pull request. the repo's agents guide explains the layout and the commands.
