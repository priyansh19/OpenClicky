Part 1 · install to first answer

Three ways to meet Clicky

All three use the real hold key, the real mic and the real triangle; there are no slides or videos. The goal is a spoken answer within 60 seconds of the installer finishing, measured on the laptop. Step through each one.

Recommendation: build A as the spine. B's practice area opens on its own when the real desktop is a bad teacher (nothing open, pointing off by more than 24 px, or a screen reader running). Part 2 · Clicky as a Windows teacher

Point, explain, guide, do it with me, do it

No other Windows assistant teaches on your own screen and checks that you actually did the step. Clicky picks the mode from how you ask, and one word moves you up or down the ladder.

1Point"Where's…" "What's this?"

The triangle flies to it, labels it, says one sentence.

2Explain"Why…" "What's the difference…"

Points, then says why it's there. Can draw an arrow.

3Guide"How do I…" "Walk me through…"

One step card at a time. Waits until the screen shows you did it.

4Do it with me"Help me do…"

Clicky does the dull steps with a ghost cursor; you do the ones worth learning.

5Do it"Clicky, …" "Just do it"

Agent mode. Ends with "Show me how you did that".

The first lesson is the skill check

"Open File Explorer, however you usually do." Clicky watches how you do it and sets your level for each track without a quiz: Win+E in 3 s means fluent; hunting the Start menu means beginner; a Cmd+Space reflex starts the "Coming from Mac" track. No score is ever shown.

Tracks

Windows basics · File Explorer · Excel · Outlook · Settings and privacy · Keyboard shortcuts · Coming from Mac · Staying safe (fake pop-ups, scam emails). Lessons are Markdown playbooks, so hand-written and generated ones share one format.

Teach someone else

A helper records a lesson once and sends it as a file; Clicky plays it as Guide on the other person's PC ("teach my mum"). "Record a how-to" exports a redacted step guide.

Agent runs become lessons

"Show me how you did that" replays an agent run slowly with narration, then hands over: "Now you." "Watch me once" records your demo and turns it into a playbook.

Teacher MVP: Guide with screen-checked steps, the mode picker with voice switching, notch step cards with the ghost demo and hint ladder, the first lesson as skill check, and "Show me how you did that". One architecture flag: Guide has to watch the screen between key presses, which breaks today's rule that capture happens only while the key is held. It would need its own visible "Lesson · watching" state and an entry in the development plan.

Part 3 · agentic modes

Seven modes, one trust ladder

Clicky works out the mode from how you ask. How much it may do without asking changes only when you say so. Co-pilot and autopilot are one mode at two trust levels, so nobody flips a global autopilot switch and forgets it.

Notch states

Trust ladder, per app and per action

After five OKs in a row for the same kind of step in the same app, Clicky offers to stop asking. A decline or an undo drops it a level, and unused trust fades after 30 days. Sending, buying, deleting, installing and security settings never reach "trusted".

Every run leaves a receipt

The first-run "aha" is the receipt rather than the clicking: "I said one sentence, it did 40 boring clicks correctly, and told me exactly what it did and how to undo it."

Agent onboarding, in order

Guide first (day 1, no input permission needed) → rules and consent → the practice room: press Esc, grab the mouse, see the Send gate → a first real task suggested from your profile, with a plan preview → first trust offer → first background task after 3 good runs → first routine when a goal repeats → first Teach when you correct a failure.

When step 37 of 80 fails

The card says what's kept ("4 of 7 sheets exported"), why it's stuck, and what it tried, with Retry · Show me where · Skip this one · Stop and keep · Undo all. "Show me where" records you doing that one step, saves a lesson, and resumes from step 37. A failed run never says "done".

Agent MVP, in order: trust basics (classes, gate reasons, the practice room) → receipts and recovery → earned autonomy and the first-run aha → long tasks with resume → background runs → authoring and suggestions. Six new pure modules in packages/core: trust, ledger, modes, queue, routine, playbook.

What the best rivals do, and the bar to beat

These come from the rival teardown, which cites 41 sources. Vendors don't publish their onboarding times, so those numbers are inferred.

One idea from the teardown bears on decision 2: let the first answer happen before any key is entered, so sign-in comes after the "wow". Without a hosted starter, that answer would have to be scripted. That is only honest inside concept B's practice area, where the question and answer are known, and never on the real desktop.

Part 5 · from the UX red team

Fix these before any redesign

These are cheap fixes for things in today's build that will lose users. The red team walked six personas through the plan: a 65-year-old new to AI, a sales rep on a locked-down laptop, a developer with three monitors, a student without Right Ctrl in a noisy dorm, a blind NVDA user, and an IT admin evaluating 40 seats.

LOSES USERSTwo different hold keysThe done screen says Right Shift and the dashboard says Right Ctrl. Every surface should read the one setting.
LOSES USERS"You're all set" comes too earlyIt shows before the mic or key has been tested. Say "Almost there" until the first answer lands.
LOSES USERS"Allow all" looks like StopIt has the same red outline as Stop. Make it "Allow for this task", tucked in a menu, and never let it cover anything that can't be undone.
LOSES USERSRight Alt is AltGr in EuropeOn Italian and German keyboards, typing an email address would start dictation. Pick the default from the keyboard layout.
LOOKS UNFINISHEDMac window buttons on a Windows installerThe red, amber and green dots should become Windows caption buttons, or just an ×.
LOOKS UNFINISHEDThree looks in 30 secondsA beige installer, a dark dashboard with a green accent, and a blue cursor. Use one surface style, with the accent matching the cursor colour.
LOOKS UNFINISHEDEmpty stats read as broken"0 / – / –" on day one. Show "Ask your first question to see your speed."
LOOKS UNFINISHEDKey clashesHolding Right Shift for 8 s opens Filter Keys, many new laptops have a Copilot key instead of Right Ctrl, and Ctrl silences screen readers. Detect each one and offer another key.
